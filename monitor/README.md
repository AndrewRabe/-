# Ozon Price Monitor

Следит за ценами на товары Ozon и присылает сообщение в Telegram, когда цена
опускается **ниже всех ранее зафиксированных** — то есть до нового исторического
минимума. Вся история цен хранится локально, её можно выгрузить в CSV.

Работает на вашем компьютере: Windows, macOS или Linux. Никаких внешних сервисов,
кроме самого Telegram, не требуется.

---

## 1. Установка

Нужен Python 3.9 или новее — проверить: `python --version` (на macOS/Linux `python3 --version`).
Если Python не установлен, возьмите его на [python.org](https://www.python.org/downloads/)
и при установке на Windows поставьте галочку **Add Python to PATH**.

Распакуйте папку с программой, откройте в ней терминал (на Windows — «Командная
строка» или PowerShell) и выполните:

```bash
pip install -r requirements.txt
python monitor.py init
```

Команда `init` создаст файл `config.json` — это все настройки программы.

---

## 2. Telegram-бот за две минуты

1. Откройте в Telegram [@BotFather](https://t.me/BotFather), отправьте `/newbot`.
2. Придумайте имя бота и его логин (должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `7123456789:AAH...`. Скопируйте его.
4. Вставьте токен в `config.json` в поле `bot_token`.
5. Найдите своего бота по логину, откройте и нажмите **Старт**, напишите ему любое слово.
6. Выполните:

```bash
python monitor.py chatid
```

Команда покажет ваш `chat_id` — впишите его в `config.json` в поле `chat_id`.

Проверьте, что всё соединилось:

```bash
python monitor.py test-telegram
```

В Telegram должно прийти сообщение «Ozon Price Monitor на связи».

> Не хотите держать токен в файле — задайте переменные окружения
> `OZON_TG_TOKEN` и `OZON_TG_CHAT_ID`, они имеют приоритет над `config.json`.

---

## 3. Добавьте товары

Скопируйте ссылку на товар из браузера или из приложения Ozon («Поделиться» →
«Копировать ссылку») и добавьте:

```bash
python monitor.py add "https://www.ozon.ru/product/naushniki-sony-wh-1000xm5-961244530/"
```

Можно сразу дать своё название и желаемую цену:

```bash
python monitor.py add "https://www.ozon.ru/product/..." --name "Наушники Sony" --target 24990
```

Сразу несколько ссылок — через пробел. Метки `?utm_...` из ссылки удаляются автоматически.

Проверьте, что цена читается:

```bash
python monitor.py check "https://www.ozon.ru/product/..."
```

Программа покажет название, цену с Ozon Картой, обычную цену, цену до скидки
и то, каким способом эти данные получены. В базу эта команда ничего не пишет.

---

## 4. Запуск мониторинга

### Вариант А: просто оставить окно открытым (самый простой)

```bash
python monitor.py watch
```

Программа будет сама просыпаться раз в час (интервал задаётся в `config.json`)
и проверять все товары. Остановить — `Ctrl+C`. На Windows для этого есть
файл `watch.bat` — достаточно двойного щелчка.

### Вариант Б: по расписанию системы

**Windows — Планировщик задач:**

1. «Пуск» → «Планировщик заданий» → «Создать задачу».
2. Вкладка «Триггеры» → «Создать» → «Ежедневно», затем поставьте
   «Повторять задачу каждые: 1 час» в течение «1 суток».
3. Вкладка «Действия» → «Создать» → «Запуск программы» → укажите файл `run.bat`
   из папки программы.
4. На вкладке «Общие» отметьте «Выполнять вне зависимости от регистрации пользователя»,
   если хотите, чтобы работало и без входа в систему.

**macOS / Linux — cron:**

```bash
chmod +x run.sh
crontab -e
```

Добавьте строку (проверка каждый час в 7 минут — «некруглое» время выглядит
естественнее для сайта):

```
7 * * * * /полный/путь/к/ozon-price-monitor/run.sh >> /полный/путь/к/ozon-price-monitor/cron.log 2>&1
```

> На macOS может потребоваться дать Терминалу «Полный доступ к диску»
> в Системных настройках → Конфиденциальность и безопасность.

## 5. Все команды

| Команда | Что делает |
|---|---|
| `python monitor.py init` | создать `config.json` |
| `python monitor.py add <ссылка>` | добавить товар (`--name`, `--target`) |
| `python monitor.py remove <ссылка или id>` | убрать товар |
| `python monitor.py list` | список товаров, текущая цена и минимум по каждому |
| `python monitor.py check [ссылка]` | разовая проверка без записи в базу |
| `python monitor.py run` | одна проверка всех товаров (для cron / планировщика) |
| `python monitor.py watch` | постоянный мониторинг по расписанию |
| `python monitor.py test-telegram` | проверить настройки Telegram |
| `python monitor.py chatid` | узнать свой `chat_id` |
| `python monitor.py history` | последние записи истории |
| `python monitor.py history --csv prices.csv` | выгрузить всю историю в CSV (открывается в Excel) |

К любой команде можно добавить `-v` — тогда в лог попадут подробности,
это помогает разбираться, если что-то не работает.

## 6. Настройки (`config.json`)

| Параметр | Значение по умолчанию | Описание |
|---|---|---|
| `track_price` | `"card"` | какую цену считать основной: `card` — с Ozon Картой, `regular` — обычная, `original` — до скидки |
| `check_interval_minutes` | `60` | интервал в режиме `watch` |
| `delay_between_products` | `[5, 15]` | случайная пауза между товарами, секунды |
| `strategies` | `["api","html","browser"]` | порядок способов получения цены |
| `retries` | `2` | попыток на каждый способ |
| `notify_on_first_check` | `true` | прислать сообщение, когда товар взят на контроль |
| `notify_after_failures` | `3` | предупредить, если цена не читается N раз подряд |
| `proxy` | `""` | прокси вида `http://user:pass@host:port`, если нужен |
| `browser_headless` | `true` | `false` — показывать окно браузера (для отладки) |

Каждый товар в списке `products` — это объект с полями:
`url` (обязательно), `name`, `target_price`, `enabled` (`false` — временно отключить).

---

## 7. Как программа получает цену

У Ozon нет открытого API для покупателей, поэтому используются три способа
подряд, пока какой-то не сработает:

1. **`api`** — внутренний JSON-эндпоинт `composer-api.bx`, тот же, которым
   пользуется сайт. Быстро и точно.
2. **`html`** — обычная страница товара: цены лежат в атрибутах `data-state`
   у блоков виджетов.
3. **`browser`** — настоящий Chromium через Playwright. Медленно, зато проходит
   там, где первые два получают отказ.

Третий способ включается только по необходимости и требует отдельной установки:

```bash
pip install playwright
playwright install chromium
```

## 8. Если что-то не работает

**«НЕ УДАЛОСЬ: api: HTTP 403» или упоминание капчи.**
Ozon временно не отдаёт данные вашему IP. По порядку:

```bash
python monitor.py check "<ссылка>" --strategy browser
```

Если сработало — установите Playwright (см. выше), он уже стоит последним в
списке `strategies` и будет подхватываться автоматически. Ещё варианты:
увеличить интервал проверок до 2–3 часов, увеличить `delay_between_products`,
указать `proxy` в настройках.

**Цена определяется неверно.**
Ozon показывает три цены сразу, и по умолчанию отслеживается цена с Ozon Картой.
Если она вам не подходит — поставьте `"track_price": "regular"`.

Цены разных видов между собой не сравниваются: если у товара то появляется,
то пропадает цена с Ozon Картой, программа не примет эту разницу за скидку.
Поэтому после смены `track_price` минимум начинает считаться заново — в рамках
нового вида цены.

**Уведомления не приходят.**
Выполните `python monitor.py test-telegram`. Частая причина — вы не нажали
«Старт» в диалоге с ботом: Telegram запрещает ботам писать первым.

**Пришло «Не могу проверить цену».**
Товар не читается несколько раз подряд — обычно это блокировка (см. выше)
или товар снят с продажи. Повторных сообщений об этом не будет чаще раза в 12 часов.

Подробности любого запуска остаются в файле `monitor.log`.

## 9. Что где лежит

```
ozon-price-monitor/
├── monitor.py            основная программа и все команды
├── ozon_fetch.py         получение и разбор цен с Ozon
├── tests.py              самопроверка логики (python tests.py)
├── config.json           ваши настройки и список товаров
├── config.example.json   пример заполненного конфига
├── prices.db             история цен (SQLite), создаётся автоматически
├── monitor.log           журнал работы
├── run.sh / run.bat      одна проверка — для cron и Планировщика задач
└── watch.bat             постоянный мониторинг в отдельном окне (Windows)
```

`prices.db` — обычная база SQLite, её можно открыть любым просмотрщиком или
выгрузить в Excel командой `python monitor.py history --csv prices.csv`.

Чтобы убедиться, что после изменений всё в порядке: `python tests.py`
(118 проверок, сеть не используется).

---

## 10. О корректности

Программа обращается к публичным страницам товаров не чаще раза в час и с
паузами между запросами — это сопоставимо с обычным просмотром сайта человеком.
Не уменьшайте интервал до нескольких минут: это и повышает риск блокировки,
и создаёт лишнюю нагрузку. Данные используются только локально, на вашем
компьютере.
