# Домашний реестр

Система учёта домашнего имущества в одном HTML-файле (`index.html`), опубликованная как Claude Artifact — доступна с любого устройства по ссылке.

## Возможности

- **Разделы**: Дом 🏠, Машина 🚗, Техника 🔧, Вещи 📦.
- **Карточка объекта**: заметки, характеристики (модель, серийный номер, гарантия и т.п.), задачи, вопросы, планы и покупки, инструкции по ремонту и обслуживанию.
- **Сводки**: все открытые задачи и общий список «Покупки и планы» (докупить / улучшить) по всем объектам сразу.
- **Статусы**: «В строю», «На продажу» (с полем для цены и площадки), «Архив».
- **Поиск** по названиям, заметкам и характеристикам.

## Как это работает

- Приложение — один файл без сборки и зависимостей (vanilla JS + CSS, шрифты Golos Text / PT Serif / JetBrains Mono).
- Данные хранятся в самом артефакте: при изменениях страница сохраняет `data/state.json` новой версией артефакта (возможность `artifact` рантайма Claude). Резервный путь — переиздание всей страницы; локальная копия дублируется в `localStorage`.
- Светлая и тёмная темы, адаптивная вёрстка для телефона и компьютера.
