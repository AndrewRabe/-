# Домашний реестр

Система учёта домашнего имущества в одном HTML-файле (`index.html`). Работает с любого устройства через браузер, данные хранит в **вашем приватном GitHub-репозитории** — бесплатно и без сторонних сервисов.

## Возможности

- **Разделы**: Дом 🏠, Машина 🚗, Техника 🔧, Вещи 📦.
- **Карточка объекта**: фото, заметки, характеристики (модель, серийный номер, гарантия…), задачи, вопросы, планы и покупки, инструкции по ремонту и обслуживанию.
- **Сводки**: все открытые задачи и общий список «Покупки и планы» (докупить / улучшить) по всем объектам сразу.
- **Статусы**: «В строю», «На продажу» (с полем для цены и площадки), «Архив».
- **Поиск** по названиям, заметкам и характеристикам.
- **Резервная копия**: экспорт и восстановление данных одним файлом (⚙ → Резервная копия).

## Как всё устроено

- Само приложение — статичная страница, публикуется на **GitHub Pages** (workflow `.github/workflows/pages.yml` делает это автоматически при каждом пуше).
- Данные (`data/state.json`) и фото (`photos/…`) приложение сохраняет через GitHub API в **отдельный приватный репозиторий** — код публичный, данные приватные.
- На каждом устройстве один раз вводится токен доступа; он хранится только в браузере этого устройства (localStorage).
- Без настройки синхронизации приложение тоже работает — данные остаются в браузере текущего устройства.

## Настройка (один раз, ~5 минут)

1. **Создайте приватный репозиторий для данных**: на github.com нажмите «+» → *New repository*, имя `home-registry-data`, видимость **Private**, *Create repository*. Инициализировать файлами не нужно.
2. **Создайте токен**: Settings (профиля) → *Developer settings* → *Personal access tokens* → **Fine-grained tokens** → *Generate new token*:
   - *Repository access*: **Only select repositories** → `home-registry-data`;
   - *Permissions* → *Repository permissions* → **Contents: Read and write**;
   - срок действия — максимальный (по истечении просто создайте новый и введите в настройках приложения).
3. **Откройте приложение** (адрес GitHub Pages этого репозитория) → ⚙ → введите логин, имя репозитория и токен → «Проверить и сохранить».
4. Повторите шаг 3 на остальных устройствах (телефон, компьютер). На телефоне удобно добавить страницу на главный экран — будет как обычное приложение.

## Включение GitHub Pages

Workflow пытается включить Pages автоматически. Если запуск Actions завершился ошибкой про Pages — включите вручную один раз: Settings репозитория → **Pages** → *Build and deployment* → Source: **GitHub Actions**, затем перезапустите workflow (вкладка Actions → «Публикация на GitHub Pages» → *Re-run*).

## Безопасность

- Токен даёт доступ **только** к репозиторию данных и **только** к содержимому файлов — не к аккаунту.
- Токен никуда не отправляется, кроме api.github.com, и хранится в браузере устройства.
- Фото и данные лежат в приватном репозитории — их видите только вы.
