# Домашний реестр

Система учёта домашнего имущества в одном HTML-файле (`index.html`). Работает с любого устройства через браузер. Данные хранятся в **вашем** облаке на выбор: Яндекс Диск или приватный GitHub-репозиторий — бесплатно и без сторонних серверов.

## Возможности

- **Разделы**: Дом 🏠, Машина 🚗, Техника 🔧, Вещи 📦.
- **Карточка объекта**: фото, заметки, характеристики (модель, серийный номер, гарантия…), задачи, вопросы, планы и покупки, инструкции по ремонту и обслуживанию.
- **Сводки**: все открытые задачи и общий список «Покупки и планы» (докупить / улучшить) по всем объектам сразу.
- **Статусы**: «В строю», «На продажу» (с полем для цены и площадки), «Архив».
- **Календарь**: месячная сетка с задачами со сроком и мероприятиями (дата, время, привязка к объекту); импорт событий из .ics (экспорт Google/Яндекс Календаря).
- **Желания**: список покупок с целевой, текущей и минимальной ценой, ссылками на площадки и меткой «цена достигла цели»; экспорт списка в команды программы ozon-price-monitor для автоматического отслеживания цен Ozon.
- **Объявления**: для вещей «На продажу» — поля объявления (состояние, комплект, недостатки, способы передачи…), генератор текста для Авито/Юлы (кратко/подробно) с лимитами, проверками (телефон в тексте, CAPS, нет фото…) и копированием в один клик.
- **Поиск** по названиям, заметкам и характеристикам.
- **Резервная копия**: экспорт и восстановление данных одним файлом (⚙ → Резервная копия).

## Как всё устроено

- Само приложение — статичная страница, публикуется на **GitHub Pages** (workflow `.github/workflows/pages.yml`, автоматически при каждом пуше).
- Хранилище данных выбирается в настройках (⚙):
  - **Яндекс Диск** — вход по кнопке через Яндекс-аккаунт (OAuth). Данные (`state.json`) и фото лежат в папке приложения на вашем Диске (`Приложения/…`); приложение видит только эту папку, весь остальной Диск ему недоступен.
  - **GitHub** — данные и фото сохраняются через GitHub API в отдельный приватный репозиторий по fine-grained-токену.
- Токены хранятся только в браузере устройства (localStorage) и никуда, кроме API выбранного сервиса, не отправляются.
- Без настройки синхронизации приложение работает автономно на одном устройстве.
- При одновременных изменениях с двух устройств побеждает более новая версия; изменения подтягиваются при возврате на вкладку.

## Настройка: Яндекс Диск (рекомендуется, ~5 минут)

1. Откройте **oauth.yandex.ru** → «Создать приложение»:
   - название любое, например «Домашний реестр»;
   - доступ к данным: **Доступ к папке приложения на Диске** (`cloud_api:disk.app_folder`);
   - Redirect URI менять не нужно — оставьте предложенный Яндексом (`verification_code`).
2. Скопируйте **ClientID** созданного приложения.
3. В приложении: ⚙ → вкладка «Яндекс Диск» → вставьте ClientID → «Шаг 1: получить токен» → подтвердите доступ. Яндекс покажет страницу с токеном.
4. Скопируйте токен (или весь адрес страницы) → вставьте в поле «Шаг 2» → «Подключить».
5. На остальных устройствах повторите шаги 3–4 (ClientID тот же). На телефоне удобно добавить страницу на главный экран.

Токен Яндекса живёт около года; когда истечёт — приложение попросит получить его заново.

## Настройка: GitHub (альтернатива)

1. Создайте приватный репозиторий `home-registry-data` (github.com → «+» → New repository → Private).
2. Settings профиля → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate:
   *Repository access*: Only select repositories → `home-registry-data`; *Permissions* → Contents: **Read and write**.
3. В приложении: ⚙ → вкладка «GitHub» → логин, репозиторий, токен → «Проверить и сохранить».

## Включение GitHub Pages (хостинг страницы)

Workflow пытается включить Pages автоматически, но у встроенного токена Actions обычно нет на это прав. Включите вручную один раз: Settings репозитория → **Pages** → *Build and deployment* → Source: **GitHub Actions**, затем вкладка Actions → «Публикация на GitHub Pages» → *Re-run all jobs*. Адрес сайта появится в результатах workflow.

## Безопасность

- Код приложения публичный, данные — нет: они лежат в папке приложения вашего Диска или в приватном репозитории.
- Токен Яндекса ограничен папкой приложения; токен GitHub — одним репозиторием и только содержимым файлов.
- Экспорт (⚙) позволяет в любой момент забрать все данные одним файлом и переехать куда угодно.
